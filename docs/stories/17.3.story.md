## Story

As a **analytics manager**, I want to **create custom reports with metrics I choose** so that **I can present data to stakeholders in the format they need**.

**Context:**
- Fixed dashboards don't match all use cases
- Need flexibility in reporting
- Cannot share custom views with stakeholders
- No scheduled/automated reporting
- Reporting requires manual data export

## Dev Notes

### Blockers
None identified.

### Gotchas
- PDF generation: complex (requires library like jsPDF/puppeteer)
- Performance: querying large datasets for reports
- Scheduling: needs background job queue
- Caching: reports can be large, need strategy
- Timezone handling: dates in report must respect user timezone
- Email delivery: ensure reports reach inbox (not spam)
