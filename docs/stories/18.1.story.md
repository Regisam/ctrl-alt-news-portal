## Story

As a **reader**, I want to **comment on articles and discuss with other users** so that **I can engage with content and community**.

**Context:**
- No community engagement mechanism
- Users cannot discuss articles
- No way to share opinions
- Low engagement/retention
- Missing opportunity to build community

## IN Scope

- Comment creation and storage
- Nested/threaded comments (replies)
- Comment reactions (like, dislike, helpful, etc.)
- Comment moderation (flag, remove)
- Comment editing and deletion (by author/admin)
- Comment feed display per article
- Sorting (newest, top, controversial)
- User mentions (@username)
- Comment notifications (email, in-app)
- Comments API endpoints
- Comment metadata (author, timestamp, edit history)
- Comment anti-spam measures

---

## OUT of Scope

- ML-based toxicity detection
- Automatic moderation
- Comment translation
- Voice comments
- Comment threading UI (API ready, UI separate)
- Comment analytics (discussion metrics)

- Edit history: keep audit trail of edits
- Nested comment depth: avoid too deep nesting
- Performance: comment loading for popular articles
- Deleted user comments: handle gracefully
