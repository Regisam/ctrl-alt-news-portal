## Risks & Mitigations

| Risk | Impact | Mitigation |
|------|--------|-----------|
| Race conditions on concurrent upvotes | Data inconsistency (karma count wrong) | Server-side deduplication: check comment version before applying vote |
| Network latency >500ms | Poor UX, optimistic update conflicts | Monitor latency via perf metrics, fallback to polling if latency exceeds threshold |
| WebSocket not available (old browsers) | User isolation | Socket.io auto-fallback to HTTP polling built-in |
| Message ordering issues | Comments appear out of order | Client: queue updates while offline, server: use createdAt timestamps for ordering |
| Connection leaks (unclosed sockets) | Memory leaks, server resource exhaustion | Implement proper cleanup in useCommentStream hook, set socket timeout 5min |
| JWT expiration during session | Sudden disconnection without error | Refresh token before expiry, emit "auth_expired" event for UI logout prompt |
