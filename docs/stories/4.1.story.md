## Description

Implement comment threading with reply-to-reply support up to 3 nesting levels. Add parent_id foreign key to Comment schema, create reply endpoint, and implement hierarchical response structure. Support thread collapse/expand on frontend.

**Reference**: EPIC-4 (Comment Threading), Post-Sprint 3 foundation

---

## Acceptance Criteria

- [ ] GET /api/articles/:id/comments returns hierarchical tree (not flat)
- [ ] POST /api/comments/:id/reply endpoint (authenticated)
- [ ] Depth validation: max 3 nesting levels
- [ ] Reply author + karma visible in response
- [ ] Parent comment context (title, author) in reply
- [ ] Delete parent comment → soft-delete children (preserve thread)

- [ ] 400 response for depth violation

- [ ] Winston logging for reply creation
- [ ] TypeScript: 0 errors

- [ ] Client: inline reply form (not modal)

- [ ] Client: collapse/expand controls for threads
