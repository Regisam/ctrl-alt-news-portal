## Risks & Mitigations

| Risk | Impact | Probability | Mitigation |
|------|--------|-------------|-----------|
| **Setup complexity** (Jest/Vitest configuration) | Development delays | MEDIUM | Use sensible defaults, follow examples, create setup guide |
| **TypeScript integration** (test compilation issues) | Slow iteration, type errors | MEDIUM | Use ts-jest or tsconfig.test.json, validate early |
| **Slow test suite** (tests take >5 min) | Developer friction | MEDIUM | Parallel execution, test categorization (unit vs integration) |
| **Flaky tests** (intermittent failures) | CI/CD noise | MEDIUM | Proper async handling, no hardcoded timeouts, retry logic |
| **Mock maintenance** (mocks diverge from real code) | Test false confidence | LOW | Code review mocks carefully, keep in sync with implementations |

## Technical Details

### Jest Configuration (server)

```javascript
// jest.config.js
module.exports = {
  preset: 'ts-jest',
  testEnvironment: 'node',
  roots: ['<rootDir>/server'],
  testMatch: ['**/__tests__/**/*.test.ts', '**/?(*.)+(spec|test).ts'],
  moduleNameMapper: {
    '^@shared/(.*)$': '<rootDir>/shared/$1',
  },
  collectCoverageFrom: [
    'server/**/*.ts',
    '!server/**/*.d.ts',
    '!server/index.ts', // entry point
  ],
  coverageThreshold: {
    global: {
      branches: 40,
      functions: 40,
      lines: 40,
      statements: 40,
    },
    './server/lib/': {
      branches: 80,
      functions: 80,
      lines: 80,
      statements: 80,
    },
  },
};
```

### Vitest Configuration (client)

```typescript
// vitest.config.ts
import { defineConfig } from 'vitest/config';
import react from '@vitejs/plugin-react';

export default defineConfig({
  plugins: [react()],
  test: {
    environment: 'jsdom',
    globals: true,
    setupFiles: ['./client/src/__tests__/setup.ts'],
  },
  resolve: {
    alias: {
      '@': '/client/src',
      '@shared': '/shared',
    },
  },
});
```

### Test Utilities (client)

```typescript
// client/src/__tests__/test-utils.tsx
import React from 'react';
import { render as rtlRender, RenderOptions } from '@testing-library/react';
import { ThemeProvider } from '@/contexts/ThemeContext';

function AllTheProviders({ children }: { children: React.ReactNode }) {
  return <ThemeProvider>{children}</ThemeProvider>;
}

export function render(
  ui: React.ReactElement,
  options?: Omit<RenderOptions, 'wrapper'>
) {
  return rtlRender(ui, { wrapper: AllTheProviders, ...options });
}

export * from '@testing-library/react';
export { default as userEvent } from '@testing-library/user-event';
```

### Example: Component Test

```typescript
// client/src/__tests__/SearchBar.test.tsx
import { render, screen, userEvent } from './test-utils';
import SearchBar from '@/components/SearchBar';

describe('SearchBar', () => {
  it('renders search input', () => {
    render(<SearchBar />);
    const input = screen.getByPlaceholderText('Search articles...');
    expect(input).toBeInTheDocument();
  });

  it('calls onSearch when user types and submits', async () => {
    const user = userEvent.setup();
    render(<SearchBar />);
    const input = screen.getByPlaceholderText('Search articles...');
    
    await user.type(input, 'React');
    await user.keyboard('{Enter}');
    
    // Assertion depends on component behavior
    expect(input).toHaveValue('React');
  });
});
```
