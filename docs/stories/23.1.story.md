## Story

As a **user**, I want to **receive notifications in real-time** so that **I'm immediately aware of important activities**.

**Context:**
- Notifications only on request (polling)
- High latency (up to 30 seconds)
- Wasteful API calls
- Battery drain on mobile
- No real-time presence
