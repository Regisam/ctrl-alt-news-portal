## Description

Implement reputation system that calculates user badges based on karma thresholds and article count. Create reputation endpoints for viewing user reputation and global leaderboards. Badge tiers: Trusted (10+), Contributor (50+), Expert (100+), Author (5+ articles).

**Reference**: PRD section 4.1 (Reputation), Story 3.5 foundation
