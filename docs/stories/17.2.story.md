## Story

As a **content editor**, I want to **see how my articles are performing** so that **I can understand what content resonates with readers and optimize future content**.

**Context:**
- No visibility into article performance
- Cannot see which articles drive engagement
- Unknown which categories/topics perform best
- No data to guide editorial decisions
- Missing opportunities to improve content strategy

## IN Scope

- Article-level metrics (views, engagement, shares, time-on-page)
- Engagement scoring algorithm
- Popular articles ranking
- Trending content detection (24h/7d windows)
- Category performance aggregation
- Author performance tracking
- Time-series metrics (hourly/daily snapshots)
- Performance comparison tools
- Content pattern analysis (length, category, author)
- Interactive dashboard UI
- Export to CSV/PDF
- Real-time metric updates

- Automated content recommendations (separate epic)

### Blockers

### Gotchas
- Real-time vs eventual consistency: dashboard updates may lag events
- Performance at scale: querying 1M+ articles
- Attribution: which events belong to which article?
- Time zones: display times in user's timezone
- Null handling: new articles have 0 metrics initially
- Retention: how long to keep time-series data?
