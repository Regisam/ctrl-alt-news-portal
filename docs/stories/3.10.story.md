## Description

Implement email verification system with token generation and validation. Enable users to verify email addresses after registration and resend verification tokens. Include 24-hour token expiration and one-time use enforcement.

**Reference**: PRD section 2.6 (Email Verification), Story 3.9 foundation

---

## Acceptance Criteria

- [ ] GET /api/auth/verify-email/:token endpoint
- [ ] POST /api/auth/resend-verification endpoint
- [ ] Generate random 32-byte verification token on registration
- [ ] Verify token signature and expiration (24 hours)
- [ ] Mark user emailVerified = true on successful verification
- [ ] Prevent token reuse (one-time use)
- [ ] Return verification link in registration response
- [ ] Return verification link on resend request
- [ ] Resend requires unverified user (prevent spam)
- [ ] 400 response for invalid token
- [ ] 404 response when token not found
- [ ] 404 response when user not found (on resend)
- [ ] Winston logging for verification attempts
- [ ] TypeScript: 0 errors
- [ ] In-memory token store for Phase 1 (database in Phase 2)
