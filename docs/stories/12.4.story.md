## Description

Build behavioral analytics system that captures implicit user feedback signals (clicks, time-on-page, scroll depth, article completions) and uses these signals to understand user preferences beyond explicit engagement (likes, bookmarks). **Signal Types** (from Story 12.3 context):
- `click`: User clicked article link (implicit interest)
- `time_on_page`: Seconds spent reading (engagement depth)
- `scroll_depth`: % of article scrolled (completion signal)
- `completion`: User scrolled to article bottom (strong signal)

**Data Structure**:
```typescript
interface BehavioralSignal {
  userId: string;
  articleId: string;
  signalType: 'click' | 'time_on_page' | 'scroll_depth' | 'completion';
  value: number;
  timestamp: Date;
}

interface UserPreferenceProfile {
  userId: string;
  categoryScores: Record<string, number>; // 0–1 per category
  authorScores: Record<string, number>;   // 0–1 per author
  topicScores: Record<string, number>;    // 0–1 per topic tag
  lastUpdated: Date;
}
```
