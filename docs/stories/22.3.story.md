## Story

As a **system administrator**, I want to **limit API requests per user/IP** so that **the API is protected from abuse and DDoS attacks**.

**Context:**
- No rate limiting implemented
- Vulnerable to DDoS attacks
- No request throttling
- No IP blocking
- Unlimited requests possible
