## Risks & Mitigations

| Risk | Impact | Probability | Mitigation |
|------|--------|-------------|-----------|
| **Metrics collection overhead** (latency) | Performance regression | MEDIUM | Sample high-volume endpoints (10%), test <5% impact |
| **Cardinality explosion** (too many label combinations) | Memory leak / Prometheus crash | MEDIUM | Limit labels per metric, avoid unbounded dimensions |
| **Dashboard complexity** (too many panels) | Operational confusion | LOW | Start with 5 core panels, add optional panels later |
| **Prometheus retention storage** (disk full) | Downtime / lost metrics | LOW | 7d retention appropriate, monitor disk usage weekly |
| **Grafana learning curve** (team unfamiliar) | Slow troubleshooting | LOW | Live demo in Story 8.5 training |

## Technical Details

### Prometheus Client Setup

```typescript
// server/middleware/metricsMiddleware.ts
import { register, Counter, Histogram, Gauge } from '@prometheus/client';

// Define metrics
const httpRequestDuration = new Histogram({
  name: 'http_request_duration_seconds',
  help: 'Duration of HTTP request in seconds',
  labelNames: ['method', 'route', 'status_code'],
  buckets: [0.01, 0.05, 0.1, 0.5, 1, 2, 5],
});

const httpRequestTotal = new Counter({
  name: 'http_request_total',
  help: 'Total HTTP requests',
  labelNames: ['method', 'route', 'status_code'],
});

const httpErrorsTotal = new Counter({
  name: 'http_errors_total',
  help: 'Total HTTP errors',
  labelNames: ['method', 'route', 'error_code'],
});

const activeSessionsGauge = new Gauge({
  name: 'active_sessions',
  help: 'Number of active user sessions',
});

// Middleware to record metrics
export function metricsMiddleware(req, res, next) {
  const start = Date.now();
  
  res.on('finish', () => {
    const duration = (Date.now() - start) / 1000;
    httpRequestDuration.labels(req.method, req.route?.path || req.path, res.statusCode).observe(duration);
    httpRequestTotal.labels(req.method, req.route?.path || req.path, res.statusCode).inc();
    
    if (res.statusCode >= 400) {
      httpErrorsTotal.labels(req.method, req.route?.path || req.path, res.statusCode).inc();
    }
  });
  
  next();
}

// Export metrics endpoint
export function setupMetricsEndpoint(app) {
  app.get('/metrics', (req, res) => {
    res.set('Content-Type', register.contentType);
    res.end(register.metrics());
  });
}
```

### Metrics Schema

| Metric | Type | Labels | Example Query |
|--------|------|--------|---------------|
| `http_request_duration_seconds` | Histogram | method, route, status_code | `histogram_quantile(0.95, http_request_duration_seconds)` |
| `http_request_total` | Counter | method, route, status_code | `rate(http_request_total[5m])` |
| `http_errors_total` | Counter | method, route, error_code | `rate(http_errors_total[5m])` |
| `active_sessions` | Gauge | — | `active_sessions` |
| `articles_viewed_total` | Counter | article_id, category | `rate(articles_viewed_total[1h])` |

### Prometheus Configuration

```yaml
# prometheus.yml
global:
  scrape_interval: 15s
  evaluation_interval: 15s

scrape_configs:
  - job_name: 'ctrl-alt-news-server'
    metrics_path: '/metrics'
    static_configs:
      - targets: ['localhost:3000']
```
