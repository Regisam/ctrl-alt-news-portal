## 📊 Infrastructure Setup Checklist

### 1. Grafana Dashboard Creation
**Timeline**: 2-3 hours | **Priority**: CRITICAL

Create dashboard at: `serendipity-engine-canary`

**Metrics to track**:

#### A. Click-Through Rate (CTR) Comparison
- **Query**: CTR for control group vs treatment group
- **Expected baseline**: 7.2% (current)
- **Success target**: 8.2%+ in treatment (13% lift)
- **Graph type**: Time-series line chart
- **Refresh**: 5-minute interval

```sql
-- Example for Grafana/Prometheus
SELECT 
  timestamp,
  variant,
  AVG(click_through_rate) as ctr
FROM analytics_events
WHERE event_type = 'recommendation_shown'
  AND timestamp > NOW() - INTERVAL 24 HOURS
GROUP BY timestamp, variant
ORDER BY timestamp DESC
```

#### B. Discovery Rate
- **Metric**: % of recommendations with topic_distance > 0.6
- **Expected**: 25-30% baseline
- **Target**: 30%+ during canary
- **Calculation**: COUNT(topic_distance > 0.6) / COUNT(total_recommendations)

#### C. Ranking Latency (p50, p99)
- **p50 target**: <50ms
- **p99 target**: <100ms
- **Alert threshold**: p99 > 150ms
- **Graph type**: Distribution/heatmap

#### D. User Distribution by Phase
- **Chart**: Pie chart showing % of users in each rollout phase
- **Expected canary**: 5% users
- **Expected**: Shows real-time bucketing

#### E. Engagement Metrics (Optional but Recommended)
- Time-on-article (treatment vs control)
- Bookmark rate by variant
- Cross-topic engagement

### 2. PagerDuty Alert Configuration
**Timeline**: 1-2 hours | **Priority**: CRITICAL

Create alert rules with CRITICAL and WARNING severity:

#### Alert Rules

| Metric | Condition | Severity | Action |
|--------|-----------|----------|--------|
| **Latency p99** | > 150ms for 5 min | CRITICAL | Page on-call |
| **Latency p99** | > 120ms for 10 min | WARNING | Slack alert |
| **CTR Drop** | > 5% decrease from baseline for 15 min | CRITICAL | Page on-call |
| **CTR Drop** | > 2% decrease from baseline for 30 min | WARNING | Slack alert |
| **Embedding Stale** | Last update > 8 days | CRITICAL | Page on-call |
| **Error Rate** | > 1% errors for 5 min | CRITICAL | Page on-call |
| **Cache Miss Spike** | > 20% cache misses for 10 min | WARNING | Slack alert |

**Escalation Policy**: 
1. On-call engineer (immediate)
