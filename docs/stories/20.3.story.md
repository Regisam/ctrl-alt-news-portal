## Story

As a **developer**, I want to **extract a DTO (Data Transfer Object) layer** so that **API responses are consistent and error handling is centralized**.

**Context:**
- 23+ routers with repeated error handling patterns
- 67 instances of `res.status(400).json({ error: '...' })`
- No unified response wrapper
- Inconsistent HTTP status codes
- No validation layer between routes and business logic
