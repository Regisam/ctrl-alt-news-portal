## Description

Optimize images across the site to improve page performance and SEO ranking. Convert images to modern WebP format with JPEG fallbacks for browser compatibility. Implement lazy loading for off-screen images to reduce initial page load time. Target: reduce image payload by >50% while maintaining visual quality, improving Lighthouse image score from ~65 → ~90+.

**Business Impact:**
- Improves Largest Contentful Paint (LCP) — critical Core Web Vital for Google ranking
- Reduces page load time, improving mobile user experience (key SEO factor)
- Decreases bounce rate for users on slower networks
- Supports EPIC-10 vision: organic traffic growth through performance optimization

**Technical Context:**
- WebP format: 25-35% smaller than JPEG, 17-25% smaller than PNG
- Lazy loading: defers off-screen image loading until viewport proximity
- Modern browsers support WebP; fallback to JPEG for older browsers

## Acceptance Criteria

**Given** a user visits an article page with multiple images  
**When** the page loads  
**Then** images use modern WebP format on supported browsers and JPEG on fallback browsers

**Given** a user scrolls to images below the viewport fold  
**When** the user hasn't scrolled to them yet  
**Then** off-screen images don't load until viewport proximity (<500px)

**Given** original image assets exist  
**When** converted to WebP format  
**Then** file size reduced by >50% compared to original JPEG

**Given** Lighthouse audit runs on article page  
**When** images are optimized  
**Then** Lighthouse image score improves from ~65 to 85+

**Given** optimized images are deployed  
**When** visual comparison test runs  
**Then** no perceptible quality degradation in user-facing images

**Given** unit and integration tests exist  
**When** image optimization suite runs  
**Then** all 100% of tests pass

## Dev Notes

- Use Sharp.js (already in node_modules) for image processing
- Picture element pattern for WebP with JPEG fallback:
  ```html
  <picture>
    <source srcset="image.webp" type="image/webp" />
    <img src="image.jpg" alt="..." loading="lazy" />
  </picture>
  ```
- Quality setting: aim for imperceptible difference at 80+ quality
- Consider responsive images (srcset) for different device sizes
- Monitor: Largest Contentful Paint (LCP) metric
