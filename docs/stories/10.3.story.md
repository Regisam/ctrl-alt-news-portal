## Description

Generate dynamic `sitemap.xml` for all article pages and configure `robots.txt` to guide search engine crawlers. Enable search engines to discover and index all articles efficiently. Sitemap must auto-generate based on article metadata (publication date, category, modification date). Robots.txt must allow crawling of articles while protecting admin/internal routes.

**Reference**: EPIC-10 (Growth & Discovery), Phase 1: SEO Foundation  
**Prerequisite**: Story 10.1 (Meta Tags) ✅ + Story 10.2 (Schema.org) ✅  
**Blocker Status**: Prerequisite for Stories 10.4-10.6 (social sharing references canonical URLs)

## Scope

### IN Scope (MVP)
- Dynamic sitemap.xml generation (all articles, homepage, category pages)
- XML sitemap includes: loc, lastmod, changefreq, priority per page type
- robots.txt configuration (allow crawling, disallow admin)
- Canonical URL tags (prevent duplicate content)
- Robots.txt rules: allow /articles, /category, /search; disallow /admin, /api/internal
- Sitemap submission via /robots.txt (standard protocol)
- Auto-update sitemap on article publish
- Metadata: publication date, modification date per article
- Testing: robots.txt syntax validation, sitemap XML validation
- Documentation: sitemap strategy and robots.txt configuration guide

### OUT of Scope
- Google Search Console submission (manual verification step)
- Sitemap image extensions
- Video sitemap
- Mobile sitemap variant
- Automatic sitemap pinging to search engines
