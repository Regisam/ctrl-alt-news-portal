## Story

As a **user**, I want to **receive push notifications** so that **I'm alerted to important updates even when not in the app**.

**Context:**
- No push notifications
- Users miss breaking news
- Low real-time engagement
- No browser notification support
- High latency on updates

## Dev Notes

### Blockers
None identified.

### Gotchas
- HTTPS required: Web Push only works over HTTPS
- Permissions: users must grant permission
- Browser support: check navigator.serviceWorker
- Subscription: save to DB, not localStorage
- VAPID keys: required for push authentication
