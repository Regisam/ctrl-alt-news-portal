## Description

Implement lightweight A/B testing framework using localStorage-based feature flags and variant assignment. Create hooks and wrapper component to enable experimentation with feature variants. Start with 2 initial experiments: home feed layout and CTA copy variations.

**Reference**: EPIC-11 Phase 3: Analytics & Insights  
**Prerequisite**: Stories 11.1, 11.6 (personalization foundation) ✅
