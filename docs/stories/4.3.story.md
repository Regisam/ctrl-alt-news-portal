## Risks & Mitigations

| Risk | Impact | Mitigation |
|------|--------|-----------|
| Unread count race conditions | Count incorrect under concurrent reads/writes | Use database transaction for read+update, cache with versioning |
| Mention detection complexity | False positives/negatives in @username parsing | Regex: `@[a-zA-Z0-9_]{3,20}`, validate against existing usernames, case-insensitive |
| WebSocket delivery guarantee | User misses notification if disconnected | Fetch unread notifications on page load, broadcast to all connected clients of user |
| Notification spam | User overwhelmed with notifications | Batch similar notifications (3 replies = 1 notification), implement mute by type |
| 24h cleanup race condition | Notification deleted while user reading it | Soft-delete with timestamp, don't hard-delete within 30s of user viewing |
