### Implementation Summary

**Algorithm Design:**
- Linear weights: reactions=1.0, bookmarks=1.5, shares=2.0
- Time decay: exponential decay over 7 days with minimum 0.1 multiplier
- Fallback: sort by views when no engagement data available
- Scoring formula: (reactions × 1.0 + bookmarks × 1.5 + shares × 2.0) × ageDecay

**Components Delivered:**
1. **trending.ts** — Pure function library with scoring algorithm and data extraction
2. **useTrending hook** — useMemo-based hook with fallback to view count sorting
