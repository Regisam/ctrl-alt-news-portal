## Description

Implement trending articles algorithm based on user engagement signals (reactions, bookmarks, shares). Create library to calculate trending scores and widget component to display top trending articles in the sidebar.

**Reference**: EPIC-11 Phase 2: Personalization & Recommendations  
**Prerequisite**: Stories 11.1, 11.3 (engagement tools) ✅

---

## Acceptance Criteria

- [ ] `trending.ts` library: calculates trending score from reactions + bookmarks + shares
- [ ] Score calculation uses time-window (recent engagement weighted higher)
- [ ] `useTrending` hook: returns top 5-10 trending articles
- [ ] `TrendingWidget` component: displays trending articles in sidebar
- [ ] Widget refreshes on user interaction or timed interval
- [ ] Correlation >80% with GA4 view count (manual validation)
- [ ] Comprehensive unit tests for algorithm
- [ ] No TypeScript errors
- [ ] Tests passing
