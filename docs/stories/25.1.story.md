## Story

As an **admin**, I want to **view real-time analytics** so that **I can monitor platform performance and user behavior instantly**.

**Context:**
- No real-time analytics dashboard
- Metrics buried in logs
- No performance visibility
- No user engagement tracking
- Slow decision-making on optimization
