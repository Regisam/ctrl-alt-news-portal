## Story

As a **developer**, I want to **automate testing and deployment with GitHub Actions** so that **every commit is validated and production is always safe**.

**Context:**
- No automated testing on PRs
- Manual deployment required
- No quality gates
- Missing CI/CD pipeline
- Risk of bad code reaching production
