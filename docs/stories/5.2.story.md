## Description

Build admin interface for article management. Enable admins to view all articles in paginated table, filter by category/status, perform bulk operations (publish, archive, delete), edit article metadata, and view engagement metrics (views, comments).

**Reference**: EPIC-5 (Admin Dashboard), Story 3.1 (Articles CRUD API foundation)

---

## Acceptance Criteria

- [ ] Articles table: paginated list (50 articles per page)
- [ ] Columns: Title, Author, Category, Status, Views, Comments, Created, Actions
- [ ] Filter options: Category, Status (DRAFT/PUBLISHED/ARCHIVED), Date range
- [ ] Search: by title, author, category (full-text)
- [ ] Bulk operations: Select multiple → Publish, Archive, Delete, Change Category
- [ ] Edit article: open modal to edit title, description, category, tags
- [ ] View metrics: click article → show views, comments, engagement sparkline
- [ ] Soft delete: articles marked ARCHIVED (not hard deleted)
- [ ] Sort: by Title, Author, Views, Comments, Created (ASC/DESC)
- [ ] Responsive: works on tablet (1024px breakpoint)
- [ ] TypeScript: 0 errors
- [ ] CodeRabbit: Pre-commit review (data handling, access control)

## Risks & Mitigations

| Risk | Impact | Mitigation |
|------|--------|-----------|
| Bulk delete accidents | Data loss | Add confirmation modal, soft delete only |
| Performance on large dataset | Slow table render | Use pagination, virtual scrolling if >10k articles |
| Unauthorized access to articles | Security breach | Enforce admin middleware on all API calls |

---

## Notes

- Soft delete preserves article history
- Pagination prevents loading all articles at once
- Bulk operations improve admin efficiency
- Metrics help admins understand engagement
