## Story

As a **product manager**, I want to **track and analyze user behavior** so that **I can understand how users interact with the platform and optimize engagement**.

**Context:**
- No user behavior tracking
- Cannot see user journeys
- Unknown which features drive engagement
- No data to inform product decisions
- Missing opportunities to improve UX

## IN Scope

- Client-side event tracking (pageviews, clicks, searches)
- Session management with unique IDs
- Event storage (in-memory + optional persistence)
- User journey reconstruction
- Conversion funnel tracking
- Retention cohort analysis
- Engagement metrics (time-on-page, scroll depth)
- User cohort grouping
- Event query API
- Analytics endpoints
- Privacy-first opt-out mechanism
- GDPR-compliant (no PII in events)

---

## OUT of Scope

- Machine learning predictions
- Real-time streaming (Kafka/Kinesis)
- Data warehouse (Snowflake/BigQuery)
- Custom event properties (initially)
- Multi-variant testing (separate epic)
- Heat maps / session replay

## Dev Notes

### Blockers
None identified.

### Gotchas
- Event volume: can grow large (1M+ events/day)
- Privacy: must not track sensitive data
- Session timeout: how long is a session? (30min default)
- Anonymization: GDPR requires user can delete events
- Performance: querying large event logs is slow
- Retention: storage vs compliance (30/90/365 days?)
