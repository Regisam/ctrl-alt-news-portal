## Description

Implement schema.org structured data (JSON-LD) on all article pages to enable rich snippets in search results and knowledge panels. Each article will include ArticleSchema, NewsArticleSchema, and BreadcrumbList schema. Enable Google Rich Results Test validation and ensure search engines fully understand article content, authorship, publication date, and category hierarchy.

**Reference**: EPIC-10 (Growth & Discovery), Phase 1: SEO Foundation  
**Prerequisite**: Story 10.1 (Meta Tags & Open Graph) ✅  
**Blocker Status**: Prerequisite for Stories 10.4-10.6 (schema enriches social sharing)

---

## Scope

### IN Scope (MVP)
- Article schema.org JSON-LD (ArticleSchema + NewsArticleSchema)
- BreadcrumbList schema for category → article navigation
- Author schema (Person type with name, url, affiliation)
- Publisher schema (Organization with logo, name, url)
- ImageObject schema for featured images (url, width, height)
- Schema generation utilities and helpers
- Google Rich Results Test validation
- Integration with ArticleDetail component
- Unit tests for schema generation (75%+ coverage)
- Documentation and team enablement

### OUT of Scope
- Event schema (future dedicated epic)
- FAQSchema or HowToSchema (not article-focused for MVP)
- Automatic OG image generation from article content (deferred to Story 10.5)
- Advanced schema microdata (only JSON-LD for now)
- Schema caching optimization (handle in performance epic 10.7-10.9)

## Risks & Mitigations

| Risk | Impact | Probability | Mitigation |
|------|--------|-------------|-----------|
| **Schema validation errors in production** | MEDIUM | MEDIUM | Automated validation tests in CI, schema.org validator integration in test suite |
| **Google search cache delays (old snippets persist)** | LOW | HIGH | Document cache TTL expectations in guide, provide Google Search Console cache clear instructions |
| **Browser JSON-LD parsing inconsistencies** | LOW | LOW | Test JSON-LD parsing across browsers, fallback to basic meta tags (Story 10.1) ensures visibility |
| **ImageObject missing width/height → snippet failure** | MEDIUM | MEDIUM | Enforce image dimensions in validation, provide sensible defaults (1200×630) |
| **Date format RFC 3339 parsing failures** | LOW | MEDIUM | Utility function tests validate ISO 8601 formatting, prevent manual date strings |
| **Author URL routing to non-existent pages** | LOW | LOW | Validate author slug generation, document author URL patterns in guide |
| **BreadcrumbList position numbering errors** | LOW | MEDIUM | Unit tests verify breadcrumb array position matches hierarchy, catch off-by-one errors |

## Technical Details

### Schema Types to Implement

```json
{
  "@context": "https://schema.org",
  "@type": "NewsArticle",
  "headline": "Article Title",
  "description": "Article excerpt...",
  "image": [
    {
      "@type": "ImageObject",
      "url": "https://...",
      "width": 1200,
      "height": 630
    }
  ],
  "datePublished": "2026-04-24T10:00:00Z",
  "dateModified": "2026-04-24T10:00:00Z",
  "author": {
    "@type": "Person",
    "name": "Author Name",
    "url": "https://domain.com/author/author-name"
  },
  "publisher": {
    "@type": "Organization",
    "name": "Ctrl Alt News",
    "logo": {
      "@type": "ImageObject",
      "url": "https://domain.com/logo.png",
      "width": 600,
      "height": 60
    },
    "url": "https://ctrlaltnews.com"
  },
  "articleSection": "AI",
  "articleBody": "Full article text...",
  "wordCount": 1200
}
```
