## Description

Implement comprehensive internationalization (i18n) framework for bilingual support (English and Portuguese). Setup translation files, create i18n middleware, ensure all UI text is translatable, and prepare infrastructure for future language additions. Project currently uses hardcoded translations in components (`t.en` and `t.pt` objects) — consolidate into centralized i18n system using react-i18next.

## Risks & Mitigations

| Risk | Impact | Mitigation |
|------|--------|-----------|
| Large refactor, many components | Potential regressions | Incremental migration, thorough testing, keep old system during transition |
| Missing translations | UI shows key names or blanks | Setup missing translation warnings, auto-generate from code |
| Complex namespacing | Hard to maintain | Clear naming convention, documentation, linting rules |
| Performance (loading translations) | Slower initial load | Code-split translations, lazy load, cache in localStorage |
| URL structure changes | SEO, routing complexity | Plan URL structure carefully, add redirects, update sitemap |

## Technical Design

### File Structure

```
public/locales/
├── en/
│   └── translation.json
└── pt/
    └── translation.json

client/src/
├── i18n.ts (configuration)
├── types/i18n.d.ts (types)
└── components/LanguageSwitcher.tsx
```

### Translation Key Naming Convention

```
common.loading
common.error
common.success
pages.home.title
pages.articles.searchPlaceholder
errors.notFound
errors.unauthorized
admin.articles.title
admin.users.filterByRole
```

### Configuration Example

```typescript
import i18n from 'i18next'
import { initReactI18next } from 'react-i18next'
import LanguageDetector from 'i18next-browser-languagedetector'

i18n
  .use(LanguageDetector)
  .use(initReactI18next)
  .init({
    resources: {
      en: { translation: require('./locales/en/translation.json') },
      pt: { translation: require('./locales/pt/translation.json') }
    },
    fallbackLng: 'en',
    interpolation: { escapeValue: false }
  })
```

### Usage in Components

```typescript
const { t, i18n } = useTranslation()

return (
  <div>
    <h1>{t('pages.home.title')}</h1>
    <button onClick={() => i18n.changeLanguage('pt')}>PT</button>
  </div>
)
```
