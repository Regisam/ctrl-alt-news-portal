## Technical Details

### GitHub Actions Workflow Structure

```yaml
# .github/workflows/ci.yml
name: CI Pipeline

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  quality-gates:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-node@v3
        with:
          node-version: 18
      
      - name: Install dependencies
        run: npm ci
      
      - name: Lint check
        run: npm run lint
      
      - name: TypeScript check
        run: npm run check
      
      - name: Run tests
        run: npm run test
      
      - name: Build production
        run: npm run build
      
      - name: Upload artifacts
        uses: actions/upload-artifact@v3
        with:
          name: dist
          path: dist/
          retention-days: 5
```

### Deployment Workflow

```yaml
# .github/workflows/deploy.yml
name: Deploy

on:
  workflow_dispatch:
    inputs:
      environment:
        description: 'Environment to deploy to'
        required: true
        type: choice
        options:
          - staging
          - production

jobs:
  deploy:
    runs-on: ubuntu-latest
    environment: ${{ github.event.inputs.environment }}
    steps:
      - uses: actions/checkout@v3
      
      - name: Download artifacts
        uses: actions/download-artifact@v3
        with:
          name: dist
          path: dist/
      
      - name: Deploy to ${{ matrix.environment }}
        run: |
          npm run deploy:${{ github.event.inputs.environment }}
      
      - name: Health check
        run: |
          curl -f ${{ secrets.DEPLOY_URL }}/health || exit 1
      
      - name: Notify on success
        run: |
          curl -X POST ${{ secrets.SLACK_WEBHOOK }} \
            -d '{"text":"✅ Deployment to ${{ github.event.inputs.environment }} successful"}'
      
      - name: Notify on failure
        if: failure()
        run: |
          curl -X POST ${{ secrets.SLACK_WEBHOOK }} \
            -d '{"text":"❌ Deployment to ${{ github.event.inputs.environment }} failed"}'
```

### Health Check Endpoints

```typescript
// server/health.ts
app.get('/health', (req, res) => {
  res.json({ status: 'ok', timestamp: new Date().toISOString() });
});

app.get('/status', (req, res) => {
  res.json({
    build: process.env.BUILD_ID,
    version: process.env.VERSION,
    environment: process.env.NODE_ENV,
  });
});
```

### Rollback Script

```bash
#!/bin/bash
# scripts/rollback.sh

PREVIOUS_COMMIT=$(git rev-parse HEAD~1)
git revert --no-edit HEAD
git push origin main

# Trigger redeploy workflow
gh workflow run deploy.yml \
  -f environment=production \
  -f revert_commit=$PREVIOUS_COMMIT
```

## Risks & Mitigations

| Risk | Impact | Mitigation |
|------|--------|-----------|
| Build failure blocks merge | CRITICAL | Pre-commit hooks validate locally |
| Deployment downtime | CRITICAL | Use blue-green deployment strategy |
| Secrets exposed in logs | CRITICAL | Never log secrets, use GitHub Secrets |
| Rollback fails | CRITICAL | Test rollback script weekly |
| Staging/prod divergence | HIGH | Use same workflow for both environments |
| Long deployment time | MEDIUM | Optimize build process, cache dependencies |
| Health check false positives | MEDIUM | Multiple independent health checks |
