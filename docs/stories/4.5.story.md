## Risks & Mitigations

| Risk | Impact | Mitigation |
|------|--------|-----------|
| Deep nesting performance (3+ levels) | Slow renders, janky animations | Memoize Comment component, use React.lazy for deep replies, virtualize large lists |
| Mobile nested indent layout | Unreadable on small screens, text cramped | Use flexbox, cap indent to 2 levels visually (collapse deeper), stack buttons vertically |
| Accessibility with nested aria-labels | Screen reader confused, label duplication | Use aria-label on collapse button only, rely on semantic HTML for nesting structure |
| Keyboard nav through deep threads | User frustration, can't reach all elements | Tab order: collapse → reply button → delete → next comment, use roving tabindex pattern |
| Animation jank on collapse/expand | Poor UX perception | Use CSS transform + transition (hardware accelerated), avoid layout-shift animations |
| Optimistic rendering conflicts | Stale UI if server rejects reply | On error: remove from state, show toast, keep form data for retry |
| Bilingual strings missing | UI shows [EN] or broken text | Extract all strings to i18n object, validate 100% coverage before merge |
