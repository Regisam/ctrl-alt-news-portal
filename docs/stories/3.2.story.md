## Description

Implement JWT-based login endpoint that validates email/password credentials, issues access tokens (15-minute expiry), and refresh tokens (7-day expiry in httpOnly cookies). Integrate with existing user registration system.

**Reference**: PRD section 2.4 (User authentication), Story 3.1 foundation

---
