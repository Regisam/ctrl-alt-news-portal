## Description

Implement token refresh endpoint to issue new access tokens using refresh tokens from httpOnly cookies. Enable client-side auto-refresh on 401 responses to maintain session continuity without requiring re-login.

**Reference**: PRD section 2.4 (Token Refresh), Story 3.2 foundation

### Implementation Summary
- Backend: Token refresh endpoint with in-memory store validation

### Files to Create/Modify

### Implementation Notes
- Refresh tokens reusable until expiry (unlike one-time tokens)
- In-memory store sufficient for Phase 1 (database in Phase 2)
- Client automatically refreshes on 401 without user intervention
- Seamless UX: expired access token doesn't interrupt user
- Build on Story 3.2 JWT foundation (refreshTokenStore already created)
