## Description

Implement token refresh endpoint to issue new access tokens using refresh tokens from httpOnly cookies. Enable client-side auto-refresh on 401 responses to maintain session continuity without requiring re-login.

**Reference**: PRD section 2.4 (Token Refresh), Story 3.2 foundation
