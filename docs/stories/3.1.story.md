## Description

Implement user registration endpoint allowing new users to create accounts with email and password. Validate input, hash passwords securely with bcrypt, prevent duplicate emails, and return user data on success.

**Reference**: PRD section 2.4 (User authentication), Epic 2 Story 2.1 foundation

---

## Acceptance Criteria

- [ ] POST /api/auth/register endpoint created
- [ ] Email format validation (regex: ^[^\s@]+@[^\s@]+\.[^\s@]+$)
- [ ] Password minimum 8 characters enforced
- [ ] Password hashing with bcrypt (10 salt rounds)
- [ ] Duplicate email prevention (409 Conflict response)
- [ ] Success response: 201 Created with user data
- [ ] Error responses: 400 (validation), 409 (duplicate), 500 (server error)
- [ ] Winston logging for registration attempts
- [ ] TypeScript: 0 errors
- [ ] No security vulnerabilities (no plaintext passwords, SQL injection, etc)
