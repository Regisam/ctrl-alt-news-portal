## Description

Enable users to follow favorite authors and implement recommendation rules to boost articles from followed writers. Build upon Story 12.1's rules engine to support author-based filtering: "IF user bookmarked articles by Author X → recommend more from Author X." This story establishes author relationship tracking and author-centric recommendation rules for EPIC-12 Phase 1.

**Reference**: EPIC-12 Phase 1: Rules Engine Foundation  
**Prerequisite**: Story 12.1 (rules engine infrastructure) ✅

## Dev Notes

**Context:**
- Author-based rules are second use case for EPIC-12 Phase 1; topic-based rules established in 12.1
- Architecture already supports author rules via RulesEngine priority system
- Author follow list stored in localStorage (same pattern as bookmarks from EPIC-11.2)
- Follower count is derived from user's follow list (not centralized backend count)

**Related Stories:**
- Prerequisite: 12.1 (rules engine foundation, YAML rule format)
- Followed by: 12.3 (recency + engagement fusion rules)
- Enables: 12.6 (author pages with full bio, social, etc.)
