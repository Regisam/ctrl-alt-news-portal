## Acceptance Criteria Details

### Authentication
- JWT token required on all endpoints (Authorization header: Bearer {token})
- 401 Unauthorized if token missing or invalid
- Token validation via verifyToken() middleware

### Profile Fields
- **id**: User ID (immutable, read-only)
- **email**: User email (changeable with verification)
- **name**: User display name (optional, up to 100 chars)
- **avatar**: Avatar URL (optional)
- **emailVerified**: Boolean (true after verification)
- **createdAt**: Timestamp (read-only, immutable)
- **googleId**: OAuth identifier (read-only if set)

### API Endpoints

**GET /api/auth/profile**
```
Headers: Authorization: Bearer {token}
Response (200): { success: true, profile: { id, email, name, avatar, emailVerified, createdAt } }
Response (401): { success: false, error: "Unauthorized" }
```

**POST /api/auth/profile/update-email**
```
Headers: Authorization: Bearer {token}
Request: { newEmail: string }
Response (200): { success: true, message: "Verification link sent to new email" }
Response (400): { success: false, error: "Invalid email format" | "New email is required" }
Response (401): { success: false, error: "Unauthorized" }
Response (409): { success: false, error: "Email already in use" }
```

**GET /api/auth/verify-email-change/:token**
```
Response (200): { success: true, message: "Email verified successfully" }
Response (400): { success: false, error: "Verification token expired" }
Response (404): { success: false, error: "Verification token not found" }
```

**POST /api/auth/profile/update-password**
```
Headers: Authorization: Bearer {token}
Request: { currentPassword: string, newPassword: string }
Response (200): { success: true, message: "Password updated successfully" }
Response (400): { success: false, error: "Current password is incorrect" | "Password must be at least 8 characters" | "New password cannot be same as current" }
Response (401): { success: false, error: "Unauthorized" }
```

**POST /api/auth/profile/update-name**
```
Headers: Authorization: Bearer {token}
Request: { name: string }
Response (200): { success: true, profile: { ...updated profile } }
Response (400): { success: false, error: "Name must not be empty" | "Name cannot exceed 100 characters" }
Response (401): { success: false, error: "Unauthorized" }
```

**POST /api/auth/profile/update-avatar**
```
Headers: Authorization: Bearer {token}
Request: { avatarUrl: string }
Response (200): { success: true, profile: { ...updated profile } }
Response (400): { success: false, error: "Invalid URL format" }
Response (401): { success: false, error: "Unauthorized" }
```

### Security Requirements
- Passwords never returned in responses or logged
- Email changes require verification (prevents email spoofing)
- Password changes require current password (prevents unauthorized changes)
- JWT token validation on all endpoints
- Password hashing: bcrypt with 10 salt rounds

### Logging
- Profile access (debug level)
- Email change requests (info level)
- Email verifications (info level)
- Password changes (info level, no passwords)
- Name updates (info level)
- Avatar updates (info level)
- All errors with context (warn/error level)
