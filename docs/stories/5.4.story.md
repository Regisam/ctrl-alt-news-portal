## Description

Build analytics dashboard for real-time insights into portal performance. Display key metrics: total views, total comments, signups (today/week/month), trending articles, engagement by category, and user growth sparklines. Enable date range filtering and metric export.

**Reference**: EPIC-5 (Admin Dashboard), Story 4.4 (Reply Counter foundation)

## Risks & Mitigations

| Risk | Impact | Mitigation |
|------|--------|-----------|
| Data aggregation slow | Dashboard lag | Use Redis cache for metrics, aggregate hourly |
| Large CSV export | Browser memory | Stream CSV download, limit to 90 days |
| Chart rendering expensive | CPU spike | Use efficient charting lib (Recharts), lazy load charts |

---

## Notes

- Analytics powered by aggregated data (not real-time individual events)
- Redis caching improves performance
- 5-minute refresh rate balances freshness vs. load
- CSV export for reporting/analysis
- Parallel with 5.2 (Articles) & 5.3 (Users)
