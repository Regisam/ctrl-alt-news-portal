## Description

Implement content-based recommendation algorithm to suggest relevant articles based on user reading history and category preferences. Create recommendations library and hook, plus widget component to display suggestions in article details and home page.

**Reference**: EPIC-11 Phase 2: Personalization & Recommendations  
**Prerequisite**: Stories 11.1, 11.2, 11.3 (engagement tools) ✅

---

## Acceptance Criteria

- [ ] `recommendations.ts` library: algorithm suggests articles by category + tag similarity
- [ ] `useRecommendations` hook: returns 5-10 relevant article recommendations
- [ ] `RecommendationsWidget` component: displays 3-5 recommendations in sidebar
- [ ] Algorithm excludes articles already read by user
- [ ] Fallback to category-based suggestions for new users
- [ ] Recommendations update when reading history changes
- [ ] Comprehensive unit tests for algorithm
- [ ] No TypeScript errors
- [ ] Tests passing
