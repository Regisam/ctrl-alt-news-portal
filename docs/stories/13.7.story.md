## Story

As a **recommendation system**, I want to **recommend new topics to users based on collaborative similarity patterns** so that **users discover topics they may enjoy based on what similar users are reading, increasing cross-topic engagement and platform stickiness**.

**Context:**
- Story 13.1-13.3 (Collaborative Filtering) established user-user similarity matrices
- Story 13.4-13.5 (Neural Networks) provides article embeddings and click predictions
- Story 13.6 (Serendipity Engine) completed content discovery outside primary interests
- Story 13.7 builds on these foundations to recommend **topics** (not articles) user should follow
- Prerequisite for Story 13.8 (Real-time Preference Adaptation)

## IN Scope

- **Topic Affinity Modeling**:
  - Per-topic engagement score from user history (articles read, bookmarks, time spent per topic)
  - Topic embeddings from article embeddings (aggregate article vectors by topic)
  - Topic preference vector for each user (normalized)
  - Infer missing topics from similar users (collaborative filling)

- **Topic Bridging Algorithm**:
  - Find topics that similar users engaged with but current user hasn't explored
  - Score based on: topic distance (embedding similarity) × engagement strength (% of similar users interested)
  - Rank topics by adoption probability

- **Topic Recommendations Widget**:
  - Display top 3-5 recommended topics
  - Show adoption probability or "% of similar users interested"
  - "Follow Topic" button → navigates to Topic Page (Story 12.6)
  - Optional explainability: "Users like you also follow AI" or "Popular among AI readers"

- **Adoption Tracking**:
  - Track when user clicks "Follow Topic"
  - Log: {userId, topicId, timestamp, source: 'topic-recommendations-widget'}
  - Measure adoption rate (% of recommended topics user follows)

- **Feature Flags & A/B Testing**:
  - Feature flag: `enable_topic_recommendations` (default: false)
  - A/B test: control (no widget) vs. treatment (with widget)
  - Bucket users deterministically

- **Analytics & Monitoring**:
  - Topic recommendation CTR: % users who click "Follow Topic"
  - Topic adoption rate: % recommended topics user follows within 7 days
  - Cross-topic engagement: increase in articles read from recommended topics
  - Comparison: recommendation-driven vs. organic topic adoption

- **Cold-Start Handling**:
  - New users: show trending topics + one serendipitous topic
  - Inactive users: show topics from similar active users

- **Tests**:
  - Unit: topic affinity computation, embedding aggregation, ranking algorithm
  - Integration: widget rendering, adoption tracking, A/B bucketing
  - Performance: <100ms per user for batch processing
  - Edge cases: new users, inactive users, single-topic users

## Technical Details

### Component Structure

```typescript
// topicRecommendations.ts

export interface TopicEngagementVector {
  topicId: string;
  engagementScore: number; // normalized [0, 1]
  articleCount: number; // articles read in this topic
  timeSpent: number; // total reading time (seconds)
  lastEngagement: Date;
}

export interface TopicAffinityInput {
  userId: string;
  userTopicHistory: TopicEngagementVector[]; // topics user has engaged with
  userEngagementProfile: number[]; // dense topic preference vector
  similarUsers: string[]; // K-nearest neighbors from Story 13.1
  similarUsersTopicHistory: Map<string, TopicEngagementVector[]>; // topic prefs of similar users
  topicEmbeddings: Map<string, number[]>; // topic embeddings (aggregated from articles)
}

export interface RecommendedTopic {
  topicId: string;
  topicName: string;
  adoptionProbability: number; // [0, 1] - likelihood user will follow
  reason: string; // explainability: "Users like you follow AI", etc.
  similarityScore: number; // how aligned with user's profile
  similarUserCount: number; // how many similar users follow this topic
}

export class TopicRecommender {
  // Compute per-topic engagement vector from user history
  computeTopicEngagementVector(
    userId: string,
    userArticles: ArticleWithTopic[]
  ): TopicEngagementVector[];

  // Aggregate article embeddings → topic embeddings
  aggregateTopicEmbeddings(
    articles: Article[],
    articleEmbeddings: Map<string, number[]>
  ): Map<string, number[]>;

  // Compute topic preference vector
  computeTopicPreferenceVector(
    userTopicHistory: TopicEngagementVector[]
  ): number[];

  // Topic bridging: find topics similar users like but current user hasn't explored
  computeTopicBridging(
    input: TopicAffinityInput
  ): RecommendedTopic[];

  // Final ranking and filtering
  rankTopics(
    candidates: RecommendedTopic[],
    topK: number = 5
  ): RecommendedTopic[];
}

// Integration with recommendation engine
export function getTopicRecommendations(
  userId: string,
  userEngagementHistory: UserEngagementHistory,
  similarUsers: string[],
  topicEmbeddings: Map<string, number[]>,
  similarUserHistories: Map<string, TopicEngagementVector[]>
): Promise<RecommendedTopic[]>;
```

## Dev Notes

### Topic Affinity Computation

**Engagement Scoring Formula:**
```
engagement_score = (articles_read / max_articles) * 0.4 + 
                   (time_spent / max_time) * 0.4 +
                   (bookmarks / max_bookmarks) * 0.2
```
Normalize to [0, 1]. Temporal decay: recent engagement (< 7 days) weighted 1.0, older decay exponentially.

### Topic Bridging Logic

1. Extract user's engaged topics (T_user)
2. Extract similar users' engaged topics (T_similar for each similar user)
3. Find candidate topics: T_candidate = union(T_similar) - T_user
4. For each candidate topic:
   - Compute topic embedding cosine similarity to user's preference vector
   - Count % of similar users who engaged (popularity among peers)
   - Adoption probability = topic_similarity × peer_popularity
5. Rank by adoption probability, return top K

### Widget Placement

- Homepage sidebar: below "Trending Articles" section
- Width: 300px, height: variable (5 topics + header)
- Mobile: collapse to carousel or hide if space constrained
- A/B test: gradually roll out (5% → 25% → 50% → 100%)

### Cold-Start Strategy

- **New users** (no read history): Show top 5 global topics + 1 serendipitous random topic
- **Inactive users** (no reads > 30 days): Show topics from most similar active users
