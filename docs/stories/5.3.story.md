## Description

Build admin interface for user management. Enable admins to view all users in paginated table, search by name/email, change user roles (USER → EDITOR → ADMIN), deactivate/reactivate accounts, and view user activity (last login, articles posted, comments).

**Reference**: EPIC-5 (Admin Dashboard), Story 2.2 (User data models), Story 5.1 (Admin Authentication)

---

## Acceptance Criteria

- [ ] Users table: paginated list (100 users per page)
- [ ] Columns: Name, Email, Role, Status, Last Login, Articles Posted, Comments, Actions
- [ ] Filter options: Role (ADMIN, EDITOR, USER), Status (ACTIVE, INACTIVE)
- [ ] Search: by name, email, full-text (case-insensitive)
- [ ] Change role: dropdown in each row (USER → EDITOR → ADMIN)
- [ ] Deactivate user: toggle in actions (soft deactivation)
- [ ] View user profile: click row → modal with full user info + activity
- [ ] Activity display: last login timestamp, articles count, comments count
- [ ] Sort: by Name, Email, Role, Last Login (ASC/DESC)
- [ ] Confirmation: ask before role change or deactivation
- [ ] Responsive: works on tablet (1024px breakpoint)
- [ ] TypeScript: 0 errors
- [ ] CodeRabbit: Pre-commit review (access control, data handling)

## Risks & Mitigations

| Risk | Impact | Mitigation |
|------|--------|-----------|
| Accidental admin demotion | Lose admin access | Add confirmation modal, log role changes |
| Unauthorized role changes | Security breach | Enforce admin check on all role change requests |
| Deactivate active admin | Lockout | Prevent deactivating self or last admin |
