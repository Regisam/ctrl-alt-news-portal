## Story

As a **operations team**, I want to **receive real-time notifications when critical alerts occur** so that **we can respond immediately without constantly monitoring dashboards**.

**Context:**
- Story 16.1 created alert system (in-memory, console logging)
- Alerts only visible if someone is watching logs
- No way to wake on-call engineer at 2am
- Need: Email + Slack notifications + escalation rules

## Dev Notes

### Blockers
None identified.

### Gotchas
- SMTP credentials are sensitive — use environment variables only
- Slack rate limits: 1 msg/sec per webhook
- Email can be slow — send asynchronously
- Time zones: use UTC for quiet hours, convert for display
- Notification storms: implement backoff strategy
