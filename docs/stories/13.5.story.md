## IN Scope

- **Neural Model Architecture**:
  - Input layer: concatenate article embedding + user engagement sequence features
  - Sequence layer: LSTM/GRU to capture user reading patterns over time
  - Attention layer: learn which features/time steps matter for prediction
  - Dense layers: feed-forward with dropout regularization
  - Output layer: sigmoid activation for binary classification (click/no-click)

- **Training Pipeline**:
  - Data source: engagement data (clicks, reads, bookmarks) from EPIC-11
  - Feature engineering: engagement vector per user (frequency, recency, diversity)
  - Labels: binary (user clicked article = 1, otherwise = 0)
  - Training method: Adam optimizer, binary cross-entropy loss
  - Hyperparameter tuning: learning rate, batch size, sequence length, hidden dims
  - Validation: holdout test set (last N days), AUC metric
  - Class imbalance: handle via weighted loss (clicks are minority class)

- **Inference**:
  - Real-time prediction during ranking (batch predict 100 articles per user)
  - Caching: cache click predictions for recently seen user-article pairs
  - Latency budget: <50ms per batch (target <10ms per article)
  - Batch encoding: use article embeddings from Story 13.4 (cached)

- **Explainability**:
  - Attention weights: show which time steps (past articles) influenced prediction
  - Feature importance: which article features (topic, author, etc.) matter
  - Model drift detection: monitor prediction distribution over time

- **Cold-Start Handling**:
  - New users: use aggregate user behavior as proxy (demographics, default prefs)
  - New articles: use article embeddings + topic similarity
  - Fallback to collaborative filtering when predictions unavailable

## Technical Details

### Component Structure

```typescript
// clickPredictionModel.ts

// Input: user engagement history + article embedding
export interface UserEngagementHistory {
  userId: string;
  engagedArticles: {
    articleId: string;
    engagementScore: number; // [0, 1] click, bookmark, read time
    timestamp: Date;
  }[];
  topicsOfInterest: string[]; // derived from history
  engagementProfile: {
    avgReadTime: number;
    clickRate: number;
    bookmarkRate: number;
    diversityScore: number; // topics read
  };
}

// Output: click prediction
export interface ClickPrediction {
  userId: string;
  articleId: string;
  clickProbability: number; // [0, 1]
  confidence: number; // softmax max
  explanation: {
    topInfluentialArticles: string[]; // from attention
    importantFeatures: string[]; // topic, author, recency, etc.
  };
}

// Model architecture
export class ClickPredictionModel {
  // LSTM sequence encoder (input: user engagement history)
  encode(history: UserEngagementHistory): number[];
  
  // Attention mechanism (learn which parts matter)
  attention(sequence: number[][], query: number[]): number;
  
  // Neural network forward pass
  predict(
    userHistory: UserEngagementHistory,
    articleEmbedding: number[],
    topicFeature: string
  ): ClickPrediction;
  
  // Training
  train(
    trainingData: TrainingExample[],
    validationData: TrainingExample[],
    config: TrainingConfig
  ): TrainingMetrics;
}

// Integration with ranking
export function rankArticles(
  articles: ArticleFeatures[],
  userHistory: UserEngagementHistory,
  clickModel: ClickPredictionModel
): RankedArticle[] {
  // Score each article by: (rules_score + cf_score) * click_prob
  return articles
    .map(article => ({
      ...article,
      score: computeHybridScore(article, userHistory) * 
             clickModel.predict(userHistory, article.embedding, article.topic)
               .clickProbability
    }))
    .sort((a, b) => b.score - a.score);
}
```

## Dev Notes

### Tech Stack Decisions
- **Framework**: TensorFlow.js (browser + Node.js compatible)
- **Sequence model**: LSTM (simpler than Transformer for this task, faster inference)
- **Attention**: Custom multiplicative attention (Bahdanau-style)
- **Loss**: Binary cross-entropy with class weights to handle click rarity

### Architecture Rationale
- LSTM: captures temporal patterns in user reading behavior
- Attention: interpretability — show which past articles/features influenced prediction
- Concatenation: simple but effective (avoid over-parameterization)
- Sigmoid output: probability interpretation [0, 1]

### Known Challenges
- Click data is imbalanced (most user-article pairs don't result in click)
  - Mitigation: weighted loss, focal loss alternative, undersampling
- Cold-start articles have no engagement history
  - Mitigation: use collaborative filtering predictions as fallback, topic similarity
- Model drift: user preferences change over time
  - Mitigation: retrain weekly, monitor prediction distribution
