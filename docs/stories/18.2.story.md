## Story

As a **user**, I want to **react with emojis to articles and comments** so that **I can express my feelings quickly without typing**.

**Context:**
- Limited to 4 reaction types (like, dislike, helpful, insightful)
- No visual/emoji feedback
- Cannot express nuanced emotions
- No sentiment analysis
- Missing engagement opportunity

## IN Scope

- Emoji reaction library (10+ emojis)
- Emoji picker framework
- Reaction tracking per user
- Reaction aggregation per article/comment
- Emoji analytics (trending, popular)
- Sentiment classification (positive, negative, neutral)
- User emoji preference learning
- Emoji ranking by frequency
- Article comparison by emoji distribution
- Emoji API endpoints
- Multi-reaction support (can react with multiple emojis)
- Reaction history tracking

---

## OUT of Scope

- Emoji picker UI (API ready, UI separate)
- Custom emoji uploads
- Animated emoji reactions
- Real-time emoji notifications
- Emoji leaderboards
- Emoji gift/rewards system
