## Story

As a **platform team**, I want to **enforce rate limits on API endpoints** so that **we prevent abuse, protect backend resources, and ensure fair access for all users**.

**Context:**
- Production traffic unpredictable (spike → resource exhaustion)
- No protection against bots or malicious clients
- Single user can consume all capacity (DoS)
- Need: Per-user + per-IP rate limits with graceful degradation

## Dev Notes

### Blockers
None identified.

### Gotchas
- Rate limit state can grow large (memory issue) — implement cleanup
- Distributed systems: in-memory doesn't sync across servers — use Redis
- Time synchronization: clock skew between servers → UTC always
- User identification: not all requests have auth — fall back to IP
- Whitelist vs public endpoints: don't rate limit /health but do rate limit /api
