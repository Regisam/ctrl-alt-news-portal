## Description

Enable users to save articles for later reading and access them from a dedicated reading list page. Implement bookmark functionality with toggle button in article views and create a dedicated page (`/reading-list`) to manage saved articles.

**Reference**: EPIC-11 Phase 1: Engagement Tools  
**Prerequisite**: Story 11.1 (User Preferences) ✅
