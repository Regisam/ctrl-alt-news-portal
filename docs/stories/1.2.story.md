### Database Schema (11 Models)

**Core Tables (10)**:
1. users — Authentication, roles, profile data
2. categories — Article categories (AI, Science, Robotics, Gadgets)
3. articles — Blog posts with bilingual content
4. comments — Nested comment threads
5. reactions — User reactions (like, clap)
6. bookmarks — Saved articles
7. tags — Article tags
8. article_tags — Many-to-many join table
9. contacts — Contact form submissions
10. page_views — Analytics and session tracking

**Search Index (1)**:
11. article_search_index — PostgreSQL full-text search with tsvector

### Key Design Decisions

✓ **Bilingual Content**: titleEn/titlePt instead of JSON (indexed, type-safe)
✓ **Soft Deletes**: deletedAt field for recovery and referential integrity
✓ **Denormalized viewCount**: Avoids slow COUNT(*) aggregations
✓ **Composite Keys**: ArticleTag uses (articleId, tagId) as natural PK
✓ **Self-Referencing**: Comment.parentId for nested replies (unlimited depth)
✓ **Strategic Indexes**: 23 indexes on all common query paths
✓ **Triggers**: PostgreSQL trigger auto-updates article_search_index

### Relationships

```
User (1) ──→ (N) Article (author)
User (1) ──→ (N) Comment (author)
User (1) ──→ (N) Bookmark, Reaction, PageView

Category (1) ──→ (N) Article

Article (1) ──→ (N) Comment, Reaction, Bookmark, PageView, ArticleTag
Article (1) ──→ (1) ArticleSearchIndex

Comment (1) ──→ (N) Comment (parent-child replies)

Tag (1) ──→ (N) ArticleTag
```

- `ArticleStatus`: DRAFT, PUBLISHED, ARCHIVED
- `CommentStatus`: PENDING, APPROVED, REJECTED
- `ReactionType`: LIKE, CLAP
