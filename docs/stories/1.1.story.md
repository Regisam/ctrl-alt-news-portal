## Implementation Details

### Files Created

- `server/src/logger.ts` — Winston logger configuration
- `server/src/middleware/errorHandler.ts` — Error handling + AppError class
- `server/src/middleware/requestLogger.ts` — Request logging middleware
- `server/src/routes/health.ts` — Health check route
- `server/src/routes/index.ts` — Route setup function
- `server/index.ts` — Main server (refactored)

### Dependencies Added

```json
{
  "helmet": "^8.1.0",
  "cors": "^2.8.6",
  "dotenv": "^17.4.2",
  "winston": "^3.19.0"
}
```

DevDependencies:
- `@types/cors@^2.8.19`
- `@types/helmet@^4.0.0`

### Middleware Stack

1. **helmet** — Security headers
2. **cors** — CORS (allow localhost:3000 in dev)
3. **express.json()** — JSON body parser
4. **requestLogger** — Log all requests with method, path, statusCode, duration
5. **errorHandler** — Catch and format errors

### Routes

```
GET /api/health → { status: "ok", timestamp, uptime }
GET /api/...   → (future endpoints)
```

### Environment

- `NODE_ENV`: development | production
- `PORT`: default 3000
- `CORS_ORIGIN`: default http://localhost:3000
- `LOG_LEVEL`: default info

### Error Handling

- **AppError** class: Custom errors with statusCode and code
- **Async handler**: Wraps route handlers to catch promise rejections
- **Error middleware**: Catches all errors and returns proper JSON response
