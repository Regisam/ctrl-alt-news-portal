## Description

Implement Google OAuth 2.0 authentication flow with authorization code exchange, token verification, and automatic user creation. Support linking existing accounts by email and populate user profile from Google data.

**Reference**: PRD section 2.5 (OAuth Integration), Story 3.8 foundation

## Acceptance Criteria

- [ ] GET /api/auth/oauth/google endpoint generates consent URL
- [ ] GET /api/auth/oauth/google/callback handles authorization code
- [ ] Exchanges authorization code for ID token
- [ ] Verifies token signature with Google public keys
- [ ] Auto-creates user on first login
- [ ] Links to existing email on subsequent login
- [ ] Populates name, avatar, email_verified from Google
- [ ] Issues access and refresh tokens
