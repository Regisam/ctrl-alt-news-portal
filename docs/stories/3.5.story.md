## Description

Implement comment flagging system for users and admin moderation queue for reviewing flagged comments. Support status updates (APPROVED, REJECTED, HIDDEN) with automatic karma adjustments. Create moderation queue endpoint with filtering and pagination.

**Reference**: PRD section 4.0 (Moderation), Story 3.4 foundation

---

## Acceptance Criteria

- [ ] POST /api/comments/:id/flag endpoint (authenticated users)
- [ ] GET /api/admin/moderation-queue endpoint (admin only)
- [ ] PATCH /api/admin/comments/:id/status endpoint (admin only)
- [ ] Comment statuses: PENDING, APPROVED, REJECTED, HIDDEN
- [ ] Flag reasons: spam, offensive, off-topic, misinformation
- [ ] Moderation queue filters: status, reason, date range
- [ ] Pagination support (limit, offset)
- [ ] Karma adjustment on status change (+1 APPROVED, -5 REJECTED)
- [ ] Flag count tracked per comment
- [ ] Winston logging for all moderation actions
- [ ] 401 response when not authenticated
- [ ] 403 response when not admin
- [ ] 404 response when comment not found
- [ ] TypeScript: 0 errors
