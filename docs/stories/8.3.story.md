## Risks & Mitigations

| Risk | Impact | Probability | Mitigation |
|------|--------|-------------|-----------|
| **Alert fatigue** (false positives) | Team ignores alerts | HIGH | Conservative thresholds, 1-week tuning period, <5% false positive target |
| **Alert noise** (too many alerts) | Operational burden | MEDIUM | Use alert grouping & inhibition rules to suppress duplicates |
| **Notification channel outage** (Slack/email down) | Alerts don't reach team | LOW | Fallback to email, maintain oncall phone number as backup |
| **Escalation cascade** (alerting too aggressive) | Unnecessary page-outs | MEDIUM | Configure escalation time windows (5 min before L2 page) |
| **Threshold tuning** (hard to get right) | Time-consuming iteration | MEDIUM | Document baseline thresholds, track tuning in runbook |

## Technical Details

### Alert Rules (prometheus-alerts.yml)

```yaml
groups:
  - name: application_alerts
    interval: 30s
    rules:
      # High error rate alert
      - alert: HttpErrorRateHigh
        expr: rate(http_errors_total[5m]) > 0.05
        for: 1m
        annotations:
          summary: "High error rate detected"
          description: "Error rate is {{ $value }} errors/sec"
          runbook: "https://wiki/runbook/high-error-rate"

      # High latency alert
      - alert: HttpLatencyHigh
        expr: histogram_quantile(0.99, http_request_duration_seconds) > 2
        for: 2m
        annotations:
          summary: "High request latency detected"
          description: "P99 latency is {{ $value }}s"
          runbook: "https://wiki/runbook/high-latency"

      # High memory usage
      - alert: MemoryUsageHigh
        expr: process_resident_memory_bytes > 500000000
        for: 5m
        annotations:
          summary: "High memory usage detected"
          description: "Memory usage is {{ $value | humanize }}B"

      # High CPU usage
      - alert: CpuUsageHigh
        expr: rate(process_cpu_seconds_total[5m]) > 0.8
        for: 5m
        annotations:
          summary: "High CPU usage detected"
          description: "CPU usage is {{ $value | humanizePercentage }}"
```

### AlertManager Configuration

```yaml
# alertmanager.yml
global:
  resolve_timeout: 5m
  slack_api_url: 'https://hooks.slack.com/services/YOUR/WEBHOOK/URL'

route:
  receiver: 'default'
  group_by: ['alertname', 'instance']
  group_wait: 30s
  group_interval: 5m
  repeat_interval: 12h
  routes:
    - match:
        severity: critical
      receiver: 'critical'
      continue: true

receivers:
  - name: 'default'
    slack_configs:
      - channel: '#alerts'
        title: 'Alert: {{ .GroupLabels.alertname }}'
        text: '{{ range .Alerts }}{{ .Annotations.description }}{{ end }}'
        send_resolved: true

  - name: 'critical'
    email_configs:
      - to: 'oncall@example.com'
        from: 'alertmanager@example.com'
        smarthost: 'smtp.sendgrid.net:587'
        auth_username: 'apikey'
        auth_password: 'SG.XXXXX'
        headers:
          Subject: '[CRITICAL] {{ .GroupLabels.alertname }}'
    slack_configs:
      - channel: '#critical-alerts'
        title: '🚨 CRITICAL: {{ .GroupLabels.alertname }}'

inhibit_rules:
  - source_match:
      severity: 'critical'
    target_match:
      severity: 'warning'
    equal: ['alertname', 'instance']

  - source_match_re:
      alertname: '.*HighMemory.*'
    target_match_re:
      alertname: '.*HighCpu.*'
    equal: ['instance']
```

### Test Harness (Node.js)

```typescript
// tests/alert-test-harness.ts
import http from 'http';

// Generate high error rate (trigger HttpErrorRateHigh alert)
async function testErrorRateAlert() {
  console.log('Generating high error rate...');
  for (let i = 0; i < 100; i++) {
    try {
      await fetch('http://localhost:3000/api/nonexistent');
    } catch (e) {
      // errors expected
    }
  }
  console.log('Error rate test complete. Check Slack for alert in 1-2 minutes.');
}

// Generate slow requests (trigger HttpLatencyHigh alert)
async function testLatencyAlert() {
  console.log('Generating slow requests...');
  for (let i = 0; i < 10; i++) {
    try {
      // Timeout after 3s (triggers p99 > 2s)
      await Promise.race([
        fetch('http://localhost:3000/api/articles'),
        new Promise((_, reject) => setTimeout(() => reject(new Error('timeout')), 3000))
      ]);
    } catch (e) {
      // timeouts expected
    }
  }
  console.log('Latency test complete. Check Slack for alert in 2-3 minutes.');
}

// Run tests
async function main() {
  console.log('Starting alert tests...');
  await testErrorRateAlert();
  await new Promise(r => setTimeout(r, 60000)); // wait 1 min
  await testLatencyAlert();
}

main().catch(console.error);
```
