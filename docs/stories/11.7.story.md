## Description

Implement behavioral analytics tracking for reading metrics: scroll depth (% of article read) and time on page. Create library to calculate these metrics and hook to emit GA4 custom events at milestone points (25%, 50%, 75%, 100%).

**Reference**: EPIC-11 Phase 3: Analytics & Insights
