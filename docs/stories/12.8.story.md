## Story

As a **reader**, I want to see **trending articles in my areas of interest** in a sidebar widget so that **I discover relevant content without leaving the current page**.

**Context:**
- Story 12.7 (Smart Digest) established recommendation ranking
- EPIC-11 provides user interest data (scroll depth, bookmarks, reading time)
- Story 12.6 (Topic Pages) proved demand for curated content
- Widget builds on existing rules engine + ML models from 12.1-12.5

- **Performance**:

### Cache Strategy
- **Key:** `discovery-widget-{userId}-{topics.join(',')}`
- **TTL:** 60 minutes (configurable)
- **Storage:** sessionStorage (per-session freshness)
- **Invalidation:** Manual refresh button, or on topic preference change

### Lazy-Load Strategy
```typescript
// Use Intersection Observer
const observer = new IntersectionObserver((entries) => {
  entries.forEach((entry) => {
    if (entry.isIntersecting) {
      loadRecommendations(); // Trigger fetch only when visible
      observer.unobserve(entry.target);
    }
  });
});

observer.observe(widgetRef.current);
```

## Risks & Mitigations

| Risk | Probability | Impact | Mitigation |
|------|-------------|--------|-----------|
| Cache staleness (old recommendations shown) | Medium | Low | 1h TTL, manual refresh button, test cache invalidation |
| Lazy-load doesn't trigger (Intersection Observer not supported) | Low | Low | Polyfill available, fallback to immediate render |
| Performance regression on pages with widget | Low | Medium | Benchmark page load before/after, defer widget JS |
| Widget doesn't fit all page layouts | Medium | Low | CSS Grid/Flexbox for responsiveness, test on >10 pages |
| No user interests data (new user) | Medium | Low | Show popular articles as fallback, or hide widget |
