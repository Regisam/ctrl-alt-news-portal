## Story

As a **product manager**, I want to **run A/B tests** so that **I can validate changes before rolling out to all users**.

**Context:**
- No experimentation framework
- Changes deployed to all users immediately
- No way to measure impact
- High risk of bad features
- No data-driven decisions

### Blockers

### Gotchas
- Sample size: need enough users for significance
- Statistical power: 80% power minimum
- Interaction effects: unexpected combinations
- Segment size: ensure segments have users
- Randomization: ensure fair allocation
