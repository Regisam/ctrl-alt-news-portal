## Story

As a **user**, I want to **persist my account in the database** so that **I can log in and my data survives restarts**.

**Context:**
- Auth uses in-memory tokens (no persistence)
- Users lost on server restart
- No real authentication flow
- Sessions not stored
- Password hashing incomplete

### Blockers

### Gotchas
- Password hashing: bcrypt rounds (10-12)
- Token expiry: reasonable timeout (24h)
- Session invalidation: mark revoked
- Database transactions: atomic operations
- Password storage: never log passwords
