## Story

As a **compliance & legal team**, I want to **maintain an immutable audit log of all user actions** so that **we can prove compliance with regulations (GDPR, CCPA) and investigate security incidents**.

**Context:**
- No audit logging in place
- Cannot prove data handling compliance
- No record of who accessed what data
- Cannot investigate security incidents
- No data retention policy
- No way to honor user deletion requests

## Dev Notes

### Blockers
None identified.

### Gotchas
- GDPR right to be forgotten: must delete all user data including logs
- But audit logs must be immutable: conflict!
- Solution: Pseudonymize (replace user ID with hash) instead of delete
- Data retention: compliance vs storage costs
- Log size: every action = lots of logs (can grow large)
- Search performance: querying massive logs is slow
- Sensitive data: avoid logging passwords, tokens, PII
