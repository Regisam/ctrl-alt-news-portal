## Story

As a **operations team**, I want to **view real-time performance metrics in a live dashboard** so that **I can monitor system health at a glance without needing to curl endpoints or read logs**.

**Context:**
- Story 16.1 created monitoring endpoints (metrics, health, alerts)
- Story 16.2 created notification system
- Metrics currently only accessible via API (no UI)
- Need: Live dashboard to replace manual monitoring

## Dev Notes

### Blockers
None identified.

### Gotchas
- Data refresh can flood network — throttle requests intelligently
- Chart rendering (recharts) can be slow with large datasets
- Memory spike if keeping 24h history in-memory — paginate
- Time zones: use user's local time for display
- Responsive design: test on mobile viewports
