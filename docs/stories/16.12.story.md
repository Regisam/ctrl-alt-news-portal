## Dev Notes

### Blockers
None identified.

### Gotchas
- Load test environment vs production: differences lead to misleading results
- Warming up caches: first requests slow, subsequent fast (need warmup phase)
- External API calls: mock or use test instance (avoid rate limits)
- Database size: test data should match production size
- Measurement overhead: monitoring tools can slow down system
- False positives: brief load spike ≠ sustained capacity
