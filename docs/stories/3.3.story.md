## Description

Implement user profile endpoints for retrieving user data, fetching comments by user, and accessing public profiles. Include paginated comment retrieval and proper authentication/authorization checks.

**Reference**: PRD section 3.1 (User Profiles), Story 3.1-3.2 foundation

---

## Acceptance Criteria

- [ ] GET /api/user/me endpoint (authenticated only)
- [ ] GET /api/users/:id endpoint (public profile)
- [ ] GET /api/users/:id/comments endpoint (paginated)
- [ ] User data includes: id, email, emailVerified, name, bio, avatar, karma, role
- [ ] Public profiles exclude sensitive fields
- [ ] Comments pagination: limit (default 10, max 50) and offset
- [ ] 404 response when user not found
- [ ] 401 response when accessing /me without auth token
- [ ] Winston logging for profile access
- [ ] TypeScript: 0 errors
- [ ] No security vulnerabilities (no PII exposure)
