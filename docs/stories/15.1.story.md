## Story

As a **development team**, I want to **refactor async component testing patterns** so that **future stories don't encounter flaky tests and test infrastructure issues**.

**Context:**
- Story 14.1 revealed 36 test failures due to async component rendering
- Root causes documented in `docs/GOTCHAS_STORY_14.1.md`
- Tests fail with "element not found" because components render as `null` until data loads
- localStorage mocking gets contaminated between tests
- Pattern affects `useRecommendations`, `useDigestAnalytics`, `useDiscoveryWidget` and similar async hooks

**Goals:**
- Fix 36 failing tests
- Establish async testing patterns for team
- Prevent regression in future stories
- Document test helpers and templates

## IN Scope

- Fix 36 failing unit tests (categorized by root cause)
- Refactor localStorage mock to include teardown
- Create test helpers for async components:
  - `renderWithAsync(Component, options)`
  - `createMockLocalStorage(initialData)`
  - `waitForAsyncComponent(query)`
- Update async hooks to use sync state initialization where possible
- Document async testing patterns for team
- Prevent test contamination (cross-test data leakage)
