## IN Scope

- **Article Representation**:
  - Text encoding: title + summary (multi-field text)
  - Metadata encoding: tags, author, topic category
  - Dense vector output: learned embeddings (128D default)
  - Architecture: simple neural network or transformer-based encoder

- **Training Pipeline**:
  - Data source: EPIC-11 engagement data (clicks, bookmarks, reads)
  - Training signal: co-engagement patterns (articles clicked together → similar embeddings)
  - Training method: siamese network or contrastive loss
  - Hyperparameter tuning: embedding dimension, learning rate, batch size
  - Validation: holdout test set evaluation

- **Inference**:
  - Real-time embedding generation for new articles
  - Batch inference for corpus (precompute all article embeddings)
  - Latency budget: <10ms per article
  - Caching: cache embeddings for frequently accessed articles

- **Quality Metrics**:
  - Embedding quality: silhouette score, Davies-Bouldin index (clustering quality)
  - Semantic similarity validation: manual inspection of nearest neighbors
  - Visualization: t-SNE 2D projection for cluster analysis
  - Performance: inference latency, model size

- **Dimensionality Optimization**:
  - Tradeoff: semantic quality vs. inference speed
  - Default: 128 dimensions (balance quality/speed)
  - Configurable: 64D (fast), 256D (rich), 512D (max)

- **Edge Cases**:
  - New articles: inference on articles with limited engagement history
  - Out-of-vocabulary tokens: handle gracefully (fallback to pretrained embeddings)
  - Cold-start articles: initialize embeddings from content alone

## Technical Details

### Component Structure

```typescript
// articleEmbedding.ts — Article embedding model

export interface ArticleFeatures {
  articleId: string;
  title: string;
  summary: string;
  tags: string[];
  author: string;
  topic: string;
  engagement?: {
    clicks: number;
    bookmarks: number;
    reads: number;
  };
}

export interface ArticleEmbedding {
  articleId: string;
  embedding: number[]; // Dense vector, typically [128]
  timestamp: Date;
  dimensionality: number;
}

export interface EmbeddingConfig {
  dimensionality: number; // Default: 128, range: [64, 512]
  learningRate: number; // Default: 0.001
  batchSize: number; // Default: 32
  epochs: number; // Default: 10
  validationSplit: number; // Default: 0.2
  usePretrainedEmbeddings: boolean; // Default: false
}

// Initialize model
export async function createEmbeddingModel(
  config: EmbeddingConfig
): Promise<EmbeddingModel>

// Encode article features into embedding
export async function encodeArticle(
  article: ArticleFeatures
): Promise<ArticleEmbedding>

// Compute similarity between two articles
export function cosineSimilarity(
  embedding1: number[],
  embedding2: number[]
): number // [0, 1]

// Train model on engagement data
export async function trainEmbeddingModel(
  articles: ArticleFeatures[],
  engagementData: EngagementRecord[],
  config: EmbeddingConfig
): Promise<TrainingMetrics>

// Generate embeddings for entire corpus
export async function batchEncodeArticles(
  articles: ArticleFeatures[]
): Promise<ArticleEmbedding[]>

// Evaluate embedding quality
export async function evaluateEmbeddings(
  embeddings: ArticleEmbedding[],
  engagementData: EngagementRecord[]
): Promise<EmbeddingQualityMetrics>

// Save/load model from disk
export async function saveModel(model: EmbeddingModel, path: string)
export async function loadModel(path: string): Promise<EmbeddingModel>

// Visualization: get t-SNE projection
export async function visualizeEmbeddings(
  embeddings: ArticleEmbedding[],
  dimensions: 2 | 3
): Promise<{ articleId: string; x: number; y: number; z?: number }[]>
```

### Training Strategy

```
Input: Article features + engagement data
  ↓
Feature extraction: title, summary, tags, author, topic
  ↓
Embedding layer: learnable dense vectors [128D]
  ↓
Siamese network: learn similarity from co-engagement patterns
  ↓
Loss function: contrastive loss or triplet loss
  ↓
Optimizer: Adam (learning rate 0.001)
  ↓
Validation: 20% holdout set
  ↓
Evaluation: silhouette score, nearest neighbor validation
  ↓
Output: Trained embedding model (serialize for inference)
```

### Performance Targets

- **Training**: <30 minutes for 10K articles on single CPU
- **Inference**: <10ms per article (batch: <100ms for 100 articles)
- **Model size**: <5MB serialized
- **Embedding quality**: Silhouette score ≥0.4
- **Dimensionality**: Default 128D (configurable 64-512D)

## Dev Notes

### Tech Stack Decisions
- **Framework**: TensorFlow.js (browser + Node.js compatible) or plain TypeScript neural network
- **Training approach**: Siamese network with contrastive loss (learns similarity directly)
- **Optimization**: Adam optimizer with learning rate schedule
- **Validation**: 20% holdout set, early stopping on validation loss

### ML Pipeline
1. Extract features from articles (text + metadata)
2. Tokenize & vectorize text (word embeddings or character n-grams)
3. Concatenate with metadata embeddings
4. Pass through encoder network
5. Output dense embedding vector
6. Optimize to minimize distance between co-engaged articles

### Quality Evaluation Strategy
- **Quantitative**: Silhouette score (measure cluster cohesion)
- **Qualitative**: Manual inspection of nearest neighbors (do similar topics cluster?)
- **Visualization**: t-SNE 2D projection (visual cluster validation)
