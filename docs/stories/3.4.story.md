## Description

Implement profile update endpoints for authenticated users to modify name, bio, and avatar. Include password change endpoint with old password verification and bcrypt re-hashing.

**Reference**: PRD section 3.1 (User Profiles), Story 3.3 foundation

## Acceptance Criteria

- [ ] PUT /api/user/me endpoint (authenticated)
- [ ] Updatable fields: name (max 100 chars), bio (max 500 chars), avatar (URL)
- [ ] POST /api/user/me/password endpoint (authenticated)
- [ ] Password change requires old password verification
- [ ] New password minimum 8 characters
- [ ] Password hashing with bcrypt (10 salt rounds)
- [ ] 400 response for validation errors

- [ ] 401 response when not authenticated
- [ ] Winston logging for profile changes
- [ ] TypeScript: 0 errors
- [ ] Zod validation schemas used
