## Description

Implement admin-only authentication and authorization layer. Create admin role detection, session validation, and access control middleware. Restrict admin endpoints to authenticated admin users only.

**Reference**: EPIC-5 (Admin Dashboard), Story 2.4 foundation (authorization middleware)

---

## Acceptance Criteria

- [ ] Admin role defined in User model (ADMIN, EDITOR, USER)
- [ ] GET /api/admin/auth/check endpoint (returns current user + role)
- [ ] Admin middleware: `isAdmin()` validates role === ADMIN
- [ ] Protected admin routes: /admin/* require `isAdmin()` middleware
- [ ] JWT token includes role field
- [ ] 403 Forbidden for non-admin users on /admin/* routes
- [ ] Session validation: admin session expires after 24 hours of inactivity
- [ ] Login auditing: log admin logins with timestamp, IP
- [ ] TypeScript: 0 errors
- [ ] CodeRabbit: Pre-commit review (security checks for auth bypass)

## Risks & Mitigations

| Risk | Impact | Mitigation |
|------|--------|-----------|
| Auth bypass vulnerability | Security breach | CodeRabbit security scan, manual review of auth checks |
| Session token hijacking | Admin account compromise | Use HTTPS only, secure cookie flags, rate limiting |
| Role escalation | Non-admin user becomes admin | Validate role in JWT signature, database check |
