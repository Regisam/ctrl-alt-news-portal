ON-CALL QUICK REFERENCE

Within 5 min, investigate      → Check runbook link in alert
Don't know root cause by min 5 → Page L2 (Senior Dev)
After 15 min still unresolved  → Escalate to Manager (L3)

KEY METRICS AT A GLANCE
─────────────────────────────────────────────────────────────────────────────
Error Rate          <1% = healthy  | 5% = alert | >5% = critical
Latency (P99)       <500ms = OK    | 2s = alert | >2s = investigate
Memory              <300MB = OK    | 500MB = alert | >500MB = critical
CPU Usage           <30% = OK      | 80% = alert | >80% = urgent
Disk Space          >30% free = OK | <10% = critical

   ↓

6. Open "Ctrl Alt News - Application Metrics" dashboard

8. Generate traffic: curl http://localhost:3000 multiple times
9. Check Jaeger: http://localhost:16686 (should show traces)

KEY METRICS EXPLAINED
─────────────────────────────────────────────────────────────────────────────
Error Rate         % of requests returning 5xx errors
                   <1% = healthy, >5% = critical

Latency (P99)      99th percentile request time
                   <500ms = excellent, >2s = needs investigation

Memory Usage       Node.js heap memory consumption
                   <300MB = OK, >500MB = investigate for leak

CPU Usage          Process CPU utilization percentage
                   <30% = normal, >80% = overloaded

Database Latency   Average query execution time
                   <100ms = good, >500ms = slow query

Cache Hit Ratio    % of cache requests that hit (vs miss)
                   >80% = healthy, <50% = cache not helping
